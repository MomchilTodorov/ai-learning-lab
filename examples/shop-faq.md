# Example shop FAQ

This is an original, fictional document for testing the learning app.

## Returns

Customers can return an unused item within 30 days of delivery. Contact the shop before sending the item back. Include the order number in the message.

## Delivery

Standard delivery normally takes 3 to 5 working days after dispatch.

## Order changes

Customers can request an order change before dispatch. After dispatch, the shop cannot change the items in that parcel.

## Missing information

This FAQ does not describe international shipping, warranties, or payment methods.
